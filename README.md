# Вайбкодинг · Урок 2

Интерактивный урок для ИИ-амбассадоров iFCM GROUP. Одна HTML-страница со встроенными квизами,
тренажёрами, звуком и сертификатом. Работает офлайн после первой загрузки, ничего не требует установки.

**Тема:** как вынести приложение с ноутбука на сервер — VPS, SSH, Docker, обратный прокси,
домен, HTTPS, деплой, код-ревью и безопасность.

## Как опубликовать на GitHub Pages

1. Зайдите на [github.com](https://github.com) и нажмите **New repository**
2. Имя: `Vibecoding_2`. Выберите **Public** — на бесплатном тарифе Pages работает только с публичными репозиториями
3. **Create repository**
4. На странице репозитория нажмите **uploading an existing file** и перетащите туда `index.html`,
   папку `assets` и `README.md`
5. Внизу кнопка **Commit changes**
6. **Settings → Pages.** В блоке Source выберите **Deploy from a branch**, ветку **main**, папку **/ (root)**, нажмите **Save**
7. Подождите минуту и обновите страницу. Наверху появится адрес вида:

```
https://ваш-логин.github.io/Vibecoding_2/
```

### Если страница не открывается

| Симптом | Причина | Что делать |
|---|---|---|
| 404 после публикации | Прошло меньше минуты | Подождите и обновите страницу |
| 404 не проходит | Репозиторий приватный | На бесплатном тарифе Pages работает только с публичными |
| Страница есть, картинок нет | Папку `assets` забыли загрузить | Загрузите её целиком, имена файлов менять нельзя |
| Открывается старая версия | Кеш браузера | `Ctrl + F5` или `Cmd + Shift + R` |

## Как поправить текст

Урок собран одним файлом, править можно прямо в нём.

- Цвета — переменные в блоке `:root` в самом начале файла
- Тексты модулей лежат внутри `<section class="mod" id="m1">` и далее по номерам
- Вопросы квизов собраны в объекте `QUIZ`, там же правильные ответы и пояснения
- Данные тренажёров — объекты `GAMES` (игры-раскладки) и `SORTS` (сортировки по клику)
- Цены калькулятора — в разметке модуля 2, в `<select id="cf_cfg">`

Если что-то не получается — откройте файл в своём ИИ-агенте и попросите внести правку словами.
